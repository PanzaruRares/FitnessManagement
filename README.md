# FitnessManagement
A desktop application built with C# and .NET using Windows Forms (WinForms) designed to streamline operations and administrative tasks for gym facilities and fitness centers. Developed as part of the Programming Windows Applications (PAW - Programarea Aplicațiilor Windows) course.

Features:

Member Management: Add, update, view, and delete member profiles.

Membership Tracking: Manage subscription plans, renewal dates, and status.

Trainer & Staff Operations: Assign personal trainers to members and track class schedules.

Reporting & Data Handling:

Export data to files (Text, Binary, CSV, or XML).

Print & Print Preview capabilities for reports/receipts.

Custom UI controls and custom drawing (GDI+) for visual statistics/charts.

Database Integration: Local data persistence (SQL Server / SQLite / Local Storage).
